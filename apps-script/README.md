# ตั้งค่า Backend (Google Sheet + Apps Script)

ไม่ต้องใช้ Google Cloud Console หรือสร้าง Client ID ใดๆ ทั้งสิ้น — ใช้แค่ Google Sheet + Apps Script (ทั้งสองอย่างเป็นส่วนหนึ่งของบัญชี Google ปกติ ฟรี ไม่ต้องผูกบัตร) เจ้าหน้าที่เข้าสู่ระบบหลังบ้านด้วย **รหัสผ่านเดียวที่ใช้ร่วมกัน** ที่คุณตั้งเอง

## 1. สร้าง Google Sheet
1. ไปที่ [sheets.google.com](https://sheets.google.com) แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อ เช่น "พิทักษ์รักษ์รังสิต — Database"
2. ไม่ต้องสร้างแท็บ/หัวคอลัมน์เอง — สคริปต์จะสร้าง Drives, Stock, Orders, Finance, Timeline, TimelineItems, Sessions ให้อัตโนมัติตอนเรียกใช้ครั้งแรก

## 2. ใส่โค้ด Apps Script
1. ในสเปรดชีตเดียวกัน ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกให้หมด แล้วคัดลอกเนื้อหาไฟล์ `Code.gs` (อยู่ในโฟลเดอร์นี้) วางแทน
3. กด **บันทึก** (ไอคอนแผ่นดิสก์)

## 3. ตั้งรหัสผ่านเจ้าหน้าที่
1. ใน Apps Script editor ไปที่ **การตั้งค่าโปรเจกต์ (Project Settings)** (ไอคอนเฟือง) > **Script properties**
2. กด **Add script property** เพิ่ม property ชื่อ `ADMIN_PASSWORD` ค่าเป็นรหัสผ่านที่จะให้เจ้าหน้าที่ทุกคนใช้ร่วมกัน (ตั้งเป็นข้อความอะไรก็ได้ที่จำง่ายแต่เดายาก)
3. กด **Save script properties**

> รหัสผ่านนี้ใช้ร่วมกันทุกคน ระบบจะไม่บันทึกว่าใครเป็นคนทำรายการไหน — ถ้าอยากเปลี่ยนรหัสผ่านทีหลัง กลับมาแก้ค่า `ADMIN_PASSWORD` ที่นี่ได้ตลอด (คนที่ล็อกอินค้างอยู่จะไม่หลุดทันที แต่คนใหม่ต้องใช้รหัสใหม่)

## 4. Deploy เป็น Web App
1. ใน Apps Script editor กด **Deploy > New deployment**
2. เลือกประเภท (Type) เป็น **Web app**
3. ตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด **Deploy** แล้วอนุญาตสิทธิ์ (Authorize access) ตามที่ระบบขอ — จะมีขอสิทธิ์ **Google Drive** ด้วย (สำหรับเก็บรูปที่อัปโหลดจากเว็บ) กด **Allow** ให้ครบทุกสิทธิ์ที่ขอ ขั้นตอนนี้เป็นการอนุญาตให้สคริปต์ของคุณเองทำงาน ไม่เกี่ยวกับ Google Cloud Console แต่อย่างใด
5. คัดลอก **Web app URL** ที่ได้ (จะลงท้ายด้วย `/exec`)
6. นำ URL นี้ไปวางแทนที่ `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE` ในไฟล์ `assets/js/api.js`

> ทุกครั้งที่แก้โค้ดใน Apps Script แล้วอยากให้มีผลกับเว็บจริง ต้องกด **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) > Version: New version > Deploy** ใหม่ทุกครั้ง (URL เดิมจะยังใช้ได้)

## รูปที่อัปโหลดเก็บไว้ที่ไหน
ทุกครั้งที่มีคนอัปโหลดรูป (ทั้งฝั่งสต็อกและสลิปโอนเงินจากลูกค้า) ระบบจะสร้างไฟล์ในโฟลเดอร์ Google Drive ชื่อ **"พิทักษ์รักษ์รังสิต - รูปภาพ"** ของบัญชีที่ deploy สคริปต์นี้โดยอัตโนมัติ ตั้งค่าเป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้รูปแสดงบนเว็บได้ — เบราว์เซอร์จะบีบอัดรูปก่อนส่งเสมอ และฝั่งเซิร์ฟเวอร์จำกัดไม่เกิน ~6MB ต่อไฟล์หลังบีบอัด
